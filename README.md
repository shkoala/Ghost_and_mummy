# Are you my mummy?

Интерактивная история для начальной школы: маленькое привидение ищет маму. По дороге оно встречает паучка, лягушку, белую кошку и белую сову, собирает приметы мамы и возвращается домой.

**11 страниц · 18 заданий · уровень A1 · ориентировочно 15–25 минут.** На каждой странице нужно что-то выбрать. Лимита времени и штрафов за ошибки нет.

## Как запустить

Распакуйте архив целиком. Для игры на компьютере откройте `index.html` в современном браузере. Не перемещайте `index.html` отдельно от остальных файлов. Установка программ и сборка проекта не нужны.

## Как выложить на GitHub Pages

1. Откройте свой репозиторий на GitHub или создайте новый.
2. Загрузите **содержимое распакованного архива**, включая папку `assets`, в корень репозитория. Файл `index.html` должен быть в корне, а не внутри дополнительной папки. Сам ZIP загружать вместо файлов не нужно.
3. В настройках репозитория откройте **Pages**. В разделе **Build and deployment → Source** выберите **Deploy from a branch**, затем основную ветку (обычно `main`) и корневую папку **/(root)**. Сохраните настройки.
4. Когда GitHub закончит публикацию, откройте выданную им ссылку.

Название репозитория может быть любым: все игровые файлы используют относительные пути. Домен, сервер, API-ключи, npm и внешние библиотеки для игры не требуются.

При необходимости: [официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Для учителя

Читайте реплики по ролям. Сначала ребёнок произносит выбранную фразу, затем нажимает кнопку. Встречи построены на повторении **Have you got…? / Are you…? / Can you…?** и правильных кратких ответах.

На нижней полоске сохраняются найденные приметы: **big brown eyes · white · can fly · no legs**. Последняя примета появляется только после встречи с совой.

Кнопка с академической шапочкой открывает русские заметки для учителя и переход к любой странице. Кнопка динамика читает текущие реплики и варианты ответа, если в браузере доступна английская озвучка. Она использует голоса устройства; доступность и работа без интернета зависят от браузера и установленных голосов. Самой игре интернет после загрузки файлов не нужен.

Ошибочный ответ сопровождается подсказкой. Кнопка «дальше» открывается после верного выбора; на странице паучка нужно выбрать все три правильные карточки. «Назад» возвращает к предыдущему шагу. Прогресс сохраняется в этом браузере, если разрешено локальное сохранение. В приватном режиме или при открытии файла с диска сохранение может зависеть от настроек браузера.

Можно играть мышью, касанием или клавиатурой: **Tab**, **Enter**, **пробел**. Стрелки ← → работают для перелистывания, когда фокус не находится на кнопке или ссылке. В конце есть повторное прохождение; перед очисткой прогресса игра спрашивает подтверждение.

## Файлы и редактирование

- `index.html` — структура страницы и заметки учителю.
- `styles.css` — оформление и адаптация для маленьких экранов.
- `story.js` — весь сюжет, реплики, задания, ответы и расположение кликабельных зон.
- `app.js` — логика прохождения, озвучка, сохранение прогресса.
- `assets/` — 12 иллюстраций PNG с прозрачностью; мама и кошка уже с большими карими глазами.
- `ARTWORK.md` — сведения о перерисованных персонажах и использованных запросах.

В `story.js` у каждого задания есть `choices` (варианты), `correct` (идентификаторы верных вариантов), `wrong` (подсказка) и `after` (диалог после выбора). После существенного изменения порядка страниц или заданий измените `version` в начале `story.js`, чтобы старое сохранение не мешало новой версии.

Координаты кликабельных зон заданы в процентах относительно иллюстрации. Изменяйте их вместе с изображением. Не переименовывайте изображения без обновления ссылок в коде.
